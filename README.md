# Red Shift Puzzle

A simple mobile-friendly sliding puzzle game where the goal is to move the red tile into the target red-tile position.

## Play

Play the game here:
https://amarildogolloshi.github.io/red-shift/

## Features

- Touch-friendly and keyboard-friendly gameplay
- Target pattern and arrangement board
- Timer and level indicator
- Win modal with persistent player progress
- Printable puzzle sheets for target patterns, arrangement tiles, and combinations
